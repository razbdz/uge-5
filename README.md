Sådan fungerer spillet

Spillet varer 3 runder.

Spilleren vælger et tal mellem 0 og 4:

0 = Rock

1 = Paper

2 = Scissors

3 = Lizard

4 = Spock

Computeren vælger tilfældigt.

Vinderen af hver runde får ét point.

Efter 3 runder vises den samlede vinder eller om spillet endte uafgjort.

Regler

Rock slår Scissors og Lizard

Paper slår Rock og Spock

Scissors slår Paper og Lizard

Lizard slår Paper og Spock

Spock slår Rock og Scissors
